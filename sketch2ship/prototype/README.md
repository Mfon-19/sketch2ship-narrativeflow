# NarrativeFlow Prototype

This is a high-fidelity functional prototype of the NarrativeFlow authoring platform.

## Features Implemented
1. **Markdown Editor**: A distraction-free text area with real-time word counting and local persistence.
2. **Preview Mode**: Toggle between raw markdown and rendered HTML view.
3. **Story Library**: A dashboard to view and manage saved drafts.
4. **Reading Experience**: A minimalist serif-based view for content consumption.

## Tech Stack
- **HTML5/CSS3**: Custom property based styling for easy themes.
- **Vanilla JavaScript**: State-based view management and LocalStorage integration.

## Usage
1. Open `index.html` in any modern web browser.
2. Type your story in the 'Write' view.
3. Use `Save Draft` to store it in your browser's local memory.
4. Navigate to 'Library' to see your collection.
5. Click a story card to enter 'Reader' mode.
